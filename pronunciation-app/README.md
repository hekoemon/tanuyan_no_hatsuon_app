# えいご はつおん れんしゅうアプリ

NEW HORIZON Elementary（5年生・6年生）対応の英語発音練習アプリです。

## 動作環境

- パソコン または Chromebook / タブレット / iPad
- **Google Chrome** または **Safari（最新版）**（音声にんしき機能が必要なため。Firefoxは非対応）
- マイク（内蔵マイクでOK）

---

## 💻 Node.jsをインストールできない場合（学校のPCなどで管理者権限がないとき）

学校のパソコンは管理者権限がなくインストールできないことが多いです。その場合は、**自分のパソコンに何もインストールせずに**動かす・公開する方法が2つあります。

### 方法A：StackBlitzで今すぐブラウザ上で動かす（一番かんたん・お試し用）

ブラウザだけで、Node.jsを使うNext.jsアプリをそのまま実行できるサービスです。

1. https://stackblitz.com/ にアクセスし、無料アカウントでログイン（Googleアカウント等でOK）
2. 画面右上の「Create」→「Import from your local machine」（または「+」→「Upload folder / zip」）を選ぶ
3. お渡しした `pronunciation-app` フォルダ（または解凍前のzip）をアップロードする
4. 自動的に `npm install` → `npm run dev` が実行され、右側にプレビュー画面が表示されます
5. 画面右上に表示されるURL（例：`https://xxxx.stackblitz.io`）を、児童のタブレットやiPadのブラウザで開けば、そのまま使えます

※ StackBlitzのプレビューURLはSafariでも動作し、自動でHTTPS（暗号化された安全な接続）になるため、マイク機能も問題なく使えます。

### 方法B：Vercelに公開して、いつでも使えるURLを作る（授業で継続的に使うならこちらがおすすめ）

こちらは無料で、常時アクセスできる本番用のURL（例：`https://your-app.vercel.app`）を作れます。パソコンやサーバーを起動しっぱなしにする必要もありません。

1. https://github.com/ で無料アカウントを作る
2. GitHubの画面で「New repository」を作成（コマンド操作は不要。ブラウザ上の「Add file」→「Upload files」から、`pronunciation-app` フォルダの中身をドラッグ＆ドロップでアップロードできます）
3. https://vercel.com/ にアクセスし、「Continue with GitHub」でログイン
4. 「Add New...」→「Project」から、先ほど作成したリポジトリを選んで「Deploy」をクリック
5. 数分待つと、公開URLが発行されます。そのURLを児童のタブレットで開けば全員が使えます

いずれの方法も、教員の手元のパソコンにNode.jsをインストールする必要はありません。

### 方法C：どうしても手元で動かしたい場合

情報担当の先生に相談し、Node.jsのインストール許可をもらうのが確実です。管理者権限なしで使える「ポータブル版Node.js」もありますが、学校のセキュリティ設定によっては動かないことがあるため、上記A・Bの方法をまずお試しください。

## セットアップ手順（Node.jsをインストールできる場合・初めての方向け）

### 手順1：フォルダを開く

配布された `pronunciation-app` フォルダを、デスクトップなど分かりやすい場所に置いてください。

### 手順2：Node.jsをインストールする（まだの場合）

以下からNode.js（LTS版）をダウンロードしてインストールします。
https://nodejs.org/ja

インストール後、ターミナル（Macは「ターミナル」、Windowsは「コマンドプロンプト」または「PowerShell」）で以下を実行し、バージョンが表示されればOKです。

```
node -v
```

### 手順3：フォルダに移動する

ターミナルで、`pronunciation-app` フォルダに移動します。

```
cd デスクトップ/pronunciation-app
```

（フォルダの場所によってパスは変わります）

### 手順4：必要な部品（パッケージ）をインストールする

```
npm install
```

このコマンドは初回のみ必要です。数分かかることがあります。`node_modules` というフォルダが作られたら成功です。

### 手順5：アプリを起動する

```
npm run dev
```

「Local: http://localhost:3000」のような表示が出たら成功です。

### 手順6：ブラウザで開く

Google Chromeを開き、アドレスバーに次のように入力します。

```
http://localhost:3000
```

マイクの使用許可を聞かれたら「許可」をクリックしてください。

### 手順7：アプリを終了するとき

ターミナルで `Control + C`（Windowsは `Ctrl + C`）を押します。

## センテンス（練習問題）の編集方法

`data/sentences.json` を開くと、学年・Unit・センテンスの一覧をテキストエディタ（メモ帳やVS Codeなど）で編集できます。プログラムの知識がなくても、文章を書きかえるだけで内容を更新できます。

```json
{ "id": "5-1-1", "text": "Hello. I'm Ken.", "meaning": "こんにちは。ぼくはケンです。" }
```

- `id`：他と重ならない名前（自由に決めてOK）
- `text`：児童が練習する英語の文
- `meaning`：日本語の意味

保存後、ブラウザを再読み込み（F5キー）すると反映されます。

## タブレット・Chromebookで使うとき

同じWi-Fiに接続したタブレットから、パソコンのIPアドレス（例：`http://192.168.1.10:3000`）にアクセスすると、複数の端末から同時に利用できます。IPアドレスは `ipconfig`（Windows）や `ifconfig`（Mac）で確認できます。

## 🍎 Safariで使うときの注意点

このアプリはSafari（macOS 14.1以降 / iOS・iPadOS 14.5以降）にも対応しています。ただしSafari特有のクセがあるので、以下を確認してください。

- **HTTPS（または localhost）が必須**：Safariはセキュリティ上、`http://` の普通のアドレスではマイクを使わせてくれません。上記「方法A（StackBlitz）」「方法B（Vercel）」で発行されるURLは自動的にHTTPSになるので問題ありません。自分のパソコンで `npm run dev` する場合は `http://localhost:3000` であればSafariでも動作します。
- **初回に2段階の許可が必要**：①Webサイトのマイク使用許可、②Mac／iOSの「音声にんしき」機能そのものの許可、の2つが出ることがあります。両方とも「許可」を選んでください。
- **Macの設定**：システム設定 →「一般」→「言語と地域」内、または「Siri」の設定で音声認識が有効になっている必要があります。無効になっていると認識できません。
- **iPadで使う場合**：ホーム画面に追加した「Webアプリ（PWA）」としてではなく、**Safariアプリ内で直接開いて**使ってください（PWA化するとマイクが使えないことがあります）。

## よくあるエラーと対処法

| エラー・症状 | 対処法 |
|---|---|
| `npm install` でエラーが出る | Node.jsのバージョンが18以上か `node -v` で確認してください |
| Node.jsをインストールできない | 上記「Node.jsをインストールできない場合」のStackBlitz／Vercelをお試しください |
| マイクの音声が認識されない | Chrome／Safari最新版か、マイクの許可をしているか確認してください |
| 「このブラウザは対応していません」と出る | Firefoxでは動作しません。ChromeかSafariでお試しください |
| Safariでマイクボタンを押しても反応しない | URLが `https://` または `http://localhost` になっているか確認してください。`http://192.168.x.x` のような素のIPアドレスでは動きません |
| 画面が真っ白になる | ターミナルのエラーメッセージを確認し、`npm run dev` をもう一度実行してください |

## データの保存について

学習履歴は各端末のブラウザ内（LocalStorage）に保存されます。サーバーには送信されません。ブラウザのデータを消去すると履歴も消えるのでご注意ください。
